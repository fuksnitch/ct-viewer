# Просмотрщик КТ (собранный сайт)

Учебный просмотрщик КТ/КЛКТ (DICOM) с упором на кости лицевого черепа. Не для постановки диагноза.

Здесь только собранные файлы сайта для GitHub Pages. **Снимки обрабатываются в браузере и не покидают
компьютер**: страница загружает только саму программу, а политика безопасности (Content-Security-Policy
в `index.html`) запрещает ей обращаться к любым другим адресам.

Справка: `help.html`.
